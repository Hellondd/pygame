# NeonEngine (Pygame)

Высокопроизводительная система частиц, демонстрирующая возможности векторной математики и графических манипуляций в `pygame`.

## Использование Pygame API

В проекте задействовано более 13 функциональных блоков библиотеки:

1.  **`pygame.math.Vector2`**: Обработка движения через векторы ускорения, скорости и позиции. Позволяет вычислять физику без ручного тригонометрического разбора.
2.  **`pygame.SRCALPHA`**: Создание прозрачных слоев для реализации эффектов постобработки и свечения (bloom-effect).
3.  **`pygame.Color`**: Манипуляция цветовыми пространствами (HSLA) для создания радужных переливов.
4.  **`BLEND_RGB_ADD`**: Использование режимов смешивания для аддитивного наложения цветов, что создает эффект "неонового" свечения при наложении частиц друг на друга.
5.  **`pygame.time.Clock`**: Точная синхронизация кадровой частоты (FPS) для предотвращения ускорения физики на мощных процессорах.
6.  **`pygame.display`**: Управление аппаратным ускорением (`HWSURFACE`) и двойной буферизацией (`DOUBLEBUF`).
7.  **`pygame.draw`**: Рендеринг примитивов с динамическим изменением радиуса и альфа-канала.
8.  **`pygame.event`**: Системная обработка ввода от мыши и клавиатуры в реальном времени.
